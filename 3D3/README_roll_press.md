# RollPress_3D_10pct

This directory contains a runnable Abaqus/Explicit 3D roll pressing model.

## Files

- `build_roll_press_3d.py` builds the CAE model, writes `RollPress_3D_10pct.inp`, and defines the Abaqus job.
- `RollPress_3D_10pct.cae` is generated by the build script.
- `RollPress_3D_10pct.inp` is generated by the build script.
- `export_rolling_force.py` reads an ODB and writes roller `RF2` force history to CSV.

## Key Parameters

- Electrode: `200 x 100 x 0.15 mm`.
- Active layer: `0.133 mm`; current collector: `0.017 mm`.
- Thickness reduction: `10%`, target total thickness `0.135 mm`.
- Roller radius: `50 mm`; effective face width `120 mm`; total width `140 mm`.
- Roller line speed: `0.8 m/min = 13.333333 mm/s`.
- Rolling step duration: `7.5 s`, so the nip reaches the electrode mid-length.
- Initial strip speed: `13.333333 mm/s`.
- Placeholder stabilizing front/back tension: `0.5 MPa`.
- Top contact friction: `0.3`; bottom contact friction: `0.1`.
- Contact pairs use penalty mechanical constraint for better robustness with the
  heavy elastic rollers and thin electrode layers.
- The generated Abaqus job defaults to one CPU/domain in this Windows locale
  because multi-domain Explicit runs triggered a console encoding failure here.

## Run

Build or rebuild the model:

```bat
chcp 65001
abaqus cae noGUI=build_roll_press_3d.py
```

Run a data check:

```bat
chcp 65001
abaqus job=RollPress_3D_10pct datacheck interactive
```

Run the full analysis:

```bat
chcp 65001
abaqus job=RollPress_3D_10pct interactive
```

Export roller force after the ODB exists:

```bat
abaqus python export_rolling_force.py
```

Export a specific ODB:

```bat
abaqus python export_rolling_force.py RollPress_3D_10pct.odb rolling_force.csv
```

## Calibration Notes

The active layer and collector plastic tables are documented placeholders because
measured compression and foil hardening data were not supplied. Replace those
tables near the top of `build_roll_press_3d.py` when calibrated material data is
available. The mass scaling target is also centralized in the same file.
