# DPC 参数拟合状态：后续 3D 辊压候选

更新时间：2026-06-20

## 当前结论

用于后续 3D 辊压模型的推荐初始候选参数为：

- 候选名：`S00008B5`
- Cap Hardening 静水屈服压力整体缩放系数：`S = 0.0008`
- 摩擦角 beta：`5 deg`
- 弹性模量：`6500 MPa`
- 泊松比：`0.01`
- 密度：`2.55e-9 tonne/mm^3`

该候选来自 2D 辊压快速筛选，不是最终实测材料参数。它适合先放入 3D 模型进行验证，再根据 3D 辊后厚度、辊压力、接触压力和能量比例继续修正。

## 2D 辊压筛选结果

目标厚度为 `135 um`。有效测量区域取已经离开辊缝后的节点列，并排除后端边界列。

`S00008B5` 的结果：

- 辊后有效区域平均厚度：`135.186839 um`
- 最小厚度：`134.521589 um`
- 最大厚度：`135.739997 um`
- 厚度波动范围：`1.218408 um`
- 有效测量列数：`12`
- 是否达到厚度目标：`YES`

对比已跑过的几组：

- `S=0.0005, beta=5 deg`：平均厚度 `135.062801 um`，但最小厚度 `130.969271 um`，局部过软。
- `S=0.0007, beta=5 deg`：平均厚度 `135.190285 um`，最小厚度 `132.753700 um`，仍有局部过压。
- `S=0.0008, beta=5 deg`：平均厚度 `135.186839 um`，最小厚度 `134.521589 um`，整体更平衡。
- `beta=65 deg` 的几组虽然部分接近目标，但整体厚度偏厚或波动更大，不作为当前推荐。

## 重要限制

2D 快速筛选使用了加速设置，`S00008B5` 的最终 `ALLKE/ALLIE = 2.1906112`，动力学成分偏强。因此它只回答“这组 DPC 参数是否有能力把辊后厚度压到 135 um 附近”，不能直接证明 3D 正式模型已经满足准静态要求。

放入 3D 后必须继续检查：

- 测厚区域必须完全离开辊缝，且该区域 `CPRESS = 0`。
- 重新提取辊后实际厚度，不能用辊缝内受压厚度代替最终厚度。
- 检查 `PRESS`、`ALLPD` 和体积塑性应变，确认确实发生帽盖塑性压实。
- 检查 `ALLKE/ALLIE`、质量增加比例、辊子反力和接触压力是否合理。
- 若 3D 中出现局部过薄、畸变或质量缩放过大，应优先调整质量缩放、网格和运动时序，再考虑微调 `S`。
